# 중세국어 타이핑기 (Jungse-typer)

두벌식(2-beolsik) 자판을 기반으로, 중세국어(옛한글) 표기에 필요한 옛글자
15종을 **키보드의 숫자·기호 키에 직접 배정**한 브라우저 기반 한글 입력기입니다.
문자 키(a-z)는 이미 현대 자모로 꽉 차 있으므로, 그동안 비어 있던 숫자열과
그 옆 기호 키(`-`, `=`, `[`, `]`, `\`)를 그대로 활용했습니다. 별도의 조합
키(Shift, Alt 등)를 누르고 있을 필요 없이 한 번의 키 입력으로 바로
옛글자가 나옵니다.

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다(별도 빌드 불필요).

## 자판 구성

문자 키는 표준 두벌식 배열을 그대로 따릅니다.

| 키 | 옛글자 | 이름 |
|----|--------|------|
| 1  | ㅿ | 반치음 |
| 2  | ㆁ | 옛이응 |
| 3  | ㆆ | 여린히읗 |
| 4  | ㅸ | 순경음비읍 |
| 5  | ㅱ | 순경음미음 |
| 6  | ㆄ | 순경음피읍 |
| 7  | ㅹ | 순경음쌍비읍 |
| 8  | ㆅ | 쌍히읗 |
| 9  | ㆍ | 아래아 |
| 0  | ㆎ | 아래애 (ㆍ 다음에 `l`(ㅣ)을 쳐도 자동 결합) |
| -  | ㅺ | 합용병서 ㅅ+ㄱ |
| =  | ㅼ | 합용병서 ㅅ+ㄷ |
| [  | ㅽ | 합용병서 ㅅ+ㅂ |
| ]  | ㅴ | 합용병서 ㅂ+ㅅ+ㄱ |
| \\ | ㅵ | 합용병서 ㅂ+ㅅ+ㄷ |

ㅿ와 ㆁ은 종성(받침)으로도 쓰이므로, 모음 뒤에 다시 눌러 받침 자리에 넣을 수
있습니다. 나머지 옛글자는 초성 전용입니다.

## 유니코드 처리 방식

- 현대 자모로만 이루어진 음절은 완성형 한글(U+AC00~U+D7A3) 한 글자로
  조합해 출력합니다.
- 옛글자가 하나라도 포함된 음절, 또는 아직 종성/중성이 없는 미완성 음절은
  유니코드 한글 자모 영역(U+1100~U+11FF, 쌍히읗만 확장 영역 U+A97C)의
  초성·중성·종성 코드포인트를 그대로 이어서 출력합니다. 옛한글 조합을
  지원하는 글꼴/운영체제(예: Windows의 맑은 고딕)에서는 한 음절 모양으로
  보이고, 지원하지 않는 환경에서는 낱자가 풀어져 보일 수 있습니다.
- 사용한 옛글자 코드포인트: 반치음(초성 U+1140/종성 U+11EB), 옛이응(초성
  U+114C/종성 U+11F0), 여린히읗(U+1159), 순경음비읍(U+112B), 순경음미음
  (U+111D), 순경음피읍(U+1157), 순경음쌍비읍(U+112C), 쌍히읗(U+A97C),
  아래아(U+119E), 아래애(U+11A1), ㅅㄱ(U+112D), ㅅㄷ(U+112F), ㅅㅂ(U+1132),
  ㅂㅅㄱ(U+1122), ㅂㅅㄷ(U+1123).

## 알려진 한계

- 텍스트 중간 편집(커서를 옮겨 수정)은 지원하지 않으며, 항상 맨 끝에 이어
  씁니다.
- 위 15종 외의 드문 합용병서(네 글자 이상 등)는 다루지 않습니다.

# 중세국어 타이핑기 (Jungse-typer)

두벌식(2-beolsik) 자판을 기반으로, 중세국어(옛한글) 표기에 필요한 자모를
추가로 입력할 수 있는 브라우저 기반 한글 입력기입니다.

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다(별도 빌드 불필요).

## 자판 구성

기본 자모는 표준 두벌식 배열을 그대로 따릅니다. 아래 다섯 개의 옛글자는
` ` ` (백틱) 키를 누른 채로 해당 키를 누르면 입력되고, 화면 하단 "옛글자 잠금"
버튼을 누르면 고정해서 계속 입력할 수 있습니다.

| 키 | 현대 자모 | 옛글자(`` ` ``+키) |
|----|-----------|--------------------|
| q  | ㅂ / ㅃ   | ㅸ (순경음비읍)     |
| t  | ㅅ / ㅆ   | ㅿ (반치음)         |
| d  | ㅇ        | ㆁ (옛이응)         |
| g  | ㅎ        | ㆆ (여린히읗)       |
| k  | ㅏ        | ㆍ (아래아)         |

아래아(ㆍ) 다음에 `l`(ㅣ)을 이어 치면 자동으로 ㆎ(아래애)로 결합됩니다.

## 유니코드 처리 방식

- 현대 자모로만 이루어진 음절은 완성형 한글(U+AC00~U+D7A3) 한 글자로
  조합해 출력합니다.
- 옛글자가 하나라도 포함된 음절, 또는 아직 종성/중성이 없는 미완성 음절은
  유니코드 한글 자모 영역(U+1100~U+11FF)의 초성·중성·종성 코드포인트를
  그대로 이어서 출력합니다. 옛한글 조합을 지원하는 글꼴/운영체제(예:
  Windows의 맑은 고딕)에서는 한 음절 모양으로 보이고, 지원하지 않는 환경에서는
  낱자가 풀어져 보일 수 있습니다.
- 사용한 옛글자 코드포인트: 아래아 U+119E, ㆎ U+11A1, 반치음(초성 U+1140 /
  종성 U+11EB), 옛이응(초성 U+114C / 종성 U+11F0), 여린히읗(초성 U+1159),
  순경음비읍(초성 U+112B).

## 알려진 한계

- 텍스트 중간 편집(커서를 옮겨 수정)은 지원하지 않으며, 항상 맨 끝에 이어
  씁니다.
- 각자병서(ㆅ 등)나 세 글자 이상의 합용병서(ㅴ, ㅵ 등) 같은 드문 옛한글
  조합은 자동 결합 규칙에 포함되어 있지 않습니다.
